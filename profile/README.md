# Folkbench

Folkbench publishes AI API relay rankings, model integrity monitoring, and API quality testing. Use the public site to compare availability, stability, latency, and cost for the same model across relays, and to review probe agreement, tokens, and model fingerprints in the integrity monitor.

**[Website](https://folkbench.com/en/)** · **[Relay rankings](https://folkbench.com/en/rankings)** · **[Integrity monitor](https://folkbench.com/en/arena)** · **[API quality testing](https://folkbench.com/en/evaluations/api-quality)**

## Projects

- **[folkbench](https://github.com/Folkbench/folkbench)** — Main repository. It powers the Folkbench website and includes **Folkbench Switch**, an open-source desktop client that saves API routes and applies them locally to Claude Code, Codex, Gemini CLI, and other tools. [Website](https://folkbench.com/en/) · [Download Switch](https://github.com/Folkbench/folkbench/releases)
- **[folkbench-data](https://github.com/Folkbench/folkbench-data)** — Public snapshots of the main site's rankings, catalog, and published probe summaries.
- **[relay-rank](https://github.com/Folkbench/relay-rank)** — Snapshot site of AI API relay rankings by model: [folkbench.github.io/relay-rank](https://folkbench.github.io/relay-rank/).
- **[integrity-weekly](https://github.com/Folkbench/integrity-weekly)** — Weekly snapshot reports of model-identity probe results: [folkbench.github.io/integrity-weekly](https://folkbench.github.io/integrity-weekly/).
- **[pelican-database](https://github.com/Folkbench/pelican-database)** — A models.dev-aligned SVG and PNG database of LLM “pelican riding a bicycle” outputs used in Folkbench model authenticity detection.
